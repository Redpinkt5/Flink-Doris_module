## 重要查询规则

1. **timeinfo 时间字段过滤**：
   - 查天级趋势：WHERE LENGTH(timeinfo) = 8（如 timeinfo = '20260601'）
   - 查小时级趋势：WHERE LENGTH(timeinfo) = 10（如 timeinfo = '2026060110'）
   - **绝对不能用 LIMIT 代替日期过滤**，"最近7天"必须计算日期区间
   - 排序：ORDER BY timeinfo ASC（趋势图按时间升序）

2. **指标字段 numbers 是 Long 类型，SQL 中不带引号**

3. **动态日期计算（关键）**：
   - 当前日期：{current_date}
   - "最近7天" → timeinfo BETWEEN '{date_7days_ago}' AND '{current_date}'
   - "最近30天" → timeinfo BETWEEN '{date_30days_ago}' AND '{current_date}'
   - "本月" → timeinfo BETWEEN '{month_start}' AND '{current_date}'
   - 日期格式统一用 8 位字符串 20260629

4. **多版本/多维度趋势查询**：使用窗口函数取每个分组最新数据
   示例（按版本查ABTest趋势）：
   SELECT timeinfo, numbers, testFlag FROM (
     SELECT timeinfo, numbers, testFlag,
       ROW_NUMBER() OVER(PARTITION BY testFlag ORDER BY timeinfo DESC) as rn
     FROM AbTestPvTotal
     WHERE LENGTH(timeinfo) = 8
   ) t WHERE rn <= 10 ORDER BY timeinfo, testFlag

5. **时间格式**：保持原始 8 位（天如20260601）或 10 位（小时如2026060110），不要转成日期格式

6. **防注入**：不要在 SQL 中拼接用户输入的原始内容，只用作字段值

### chartType 可选值
- **line**：趋势折线图（适用于时间序列，如"每天订单量趋势"）
- **bar**：柱状图（适用于对比，如"各产品类目成交额"）
- **pie**：饼图（适用于占比，如"各版本占比"）
- **table**：纯表格（适用于明细数据）

### 图表选择规则

- 问对比/排名 → bar
- 问占比/比例 → pie
- 问明细/列表 → table
